# Security Rules

For all code:
- Never hard-code secrets.
- Never log credentials, tokens, PANs, sensitive authentication data, or unnecessary PII.
- Apply least privilege.
- Make authorization explicit for privileged financial actions.
- Treat external input as untrusted.
- Preserve auditability for security-sensitive and administrative actions.
- Do not weaken security controls to simplify tests; use safe test doubles instead.
