# Proposals

Ideas written up for the owner's decision. A proposal changes no scope: it is not approved or scheduled, and
`BACKLOG.md`, `ROADMAP.md` and `CURRENT_STATE.md` stay the record of what is planned.

An accepted proposal enters the project the usual way, through an ADR, a phase plan and backlog tasks. Issues the owner
has postponed belong in [`POSTPONED_ISSUES.md`](../POSTPONED_ISSUES.md), not here.
